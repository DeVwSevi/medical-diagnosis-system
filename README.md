# Medical Diagnosis System
A web-based medical diagnosis system that allows users to input symptoms and receive a preliminary diagnosis. Built with Python (Flask), HTML/CSS, and SQLite. Demonstrates backend logic, web app development, and real-world application design.

Features
- User-friendly web interface
- Symptom input and automated diagnosis suggestions
- Database storage of queries
- Modular Flask project structure

Technologies Used
- Python
- Flask
- HTML / CSS
- SQLite

How to Run
1. Clone the repository: `git clone <repo-link>`  
2. Install dependencies: `pip install -r requirements.txt`  
3. Run the app: `python app.py`  
4. Open in browser: `http://127.0.0.1:5000/`
